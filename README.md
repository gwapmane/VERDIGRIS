# VERDIGRIS

A fuzz pedal plugin (VST3 / Standalone, plus AU on Mac). The sound is a real transistor circuit (a two-transistor
fuzz stage, solved sample by sample), with Ge / Si transistors, three voicings, and six lever-switch "textures" on the
sides (Octave, Starve, Chop, Crush, Wash, Swell) that you can flip on and off in an instant, or hold for momentary use.

- `core/` the sound engine (plain C++, no JUCE) and the factory presets (`presets_factory.h`, generated by `tools/pack_gen.py`)
- `plugin/` the JUCE plugin: processor, pedal artwork, scope window, settings panels
- `assets/` the hardware sprites, enclosure renders and fonts
- `tests/selftest.cpp` automatic checks of the engine (run by the GitHub build)
- `tools/` an offline renderer and analysis scripts used while tuning the sound
- `.github/workflows/build.yml` builds Windows VST3 + Standalone and an Intel-Mac VST3 + AU + Standalone
